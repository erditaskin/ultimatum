# Historical design archive

This directory is not a production asset source. It preserves earlier experiments, the superseded product specification and unused template artwork.

- `art-review/`: original exploratory images and historical notes. Their old absolute links may no longer resolve; current references live in `../karbasan/`.
- `legacy-docs/`: snapshots of the packet/pepper/capsule prototype specification.
- `template-assets/`: unused generic `icon.png` and `splash-icon.png`, moved after verifying no application/config references. Active platform icons remain under `assets/`.

Do not import this directory into the application. Existing prototype source and save code remain intact until a tested replacement exists.
