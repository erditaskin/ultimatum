# Mimari

## Sınırlar

- `src/game`: React ve native bağımlılığı olmayan deterministik TypeScript kuralları. Saat, üretim konumu ve üretilecek tür dışarıdan verilir. Patlama breadth-first çözülür, ziyaret kümesi tekrar tetiklemeyi önler.
- `src/storage`: AsyncStorage üzerinde sürümlü, doğrulanmış kayıt ve sıralı yazma. Yükleme tamamlanmadan oyun açılmaz. Bozuk kayıt sessizce ezilmez.
- `src/ui`: React Native görünümü ve Gesture Handler etkileşimleri. Reanimated yalnızca sunumdan sorumludur. Oyun sonucu animasyondan önce hesaplanır, duruma uygulanır ve kayıt kuyruğuna eklenir. Disk yazımı asenkrondur; yazma hatası arayüzde bildirilir.
- App bileşeni küçük MVP'nin orkestrasyon katmanıdır. Gereksiz backend veya genel amaçlı oyun motoru yoktur.

## Güvenilirlik

Her aksiyon immutable durum üretir. Kaynak harcama ve sonuç tek durum geçişindedir. Arka plana geçişte gesture iptal edilir; yenilenme foreground'da hesaplanır. Güncelleme başına kayıt sıralanır; başarısız yazma kullanıcıya bildirilir. Yerel kayıt uygulama silinmesine karşı korunmaz.

## Performans

Tahta 36 hücreyle sınırlıdır. Görseller, uygulamaya gömülü ortak bir alfa atlasından native kırpma ile gösterilir. Aynı görsel kaynağı yeniden kullanılır; internet gerekmez. Hücre callback’leri seçim değişiminde sabit kalır; yalnızca değişen hücreler yeniden çizilir. Gesture görselleri native animation sürücüsünde çalışır. Saf motor için tekrarlanabilir p50/p95 benchmark, React Profiler için development commit ölçümleri tutulur. Bu ölçümler cihaz FPS sonucu değildir. Release cihaz testi ayrıca gereklidir.

## Genişleme

Denge ve kampanya tarihleri sürümlü config içindedir. Yeni kurallar önce saf motor testine eklenir. Yeni kayıt şemaları migration gerektirir. Hesap ve sunucu ekonomisi eklendiğinde cihaz saati ve yerel kayıt güven kaynağı olmaktan çıkarılmalıdır.

## Native configuration

Expo Router owns the single root route. Settings are a local modal, not a second navigation stack. iOS native files are generated by Expo CNG and excluded from Git. Audio recording and background playback permissions are disabled in app configuration. No network SDK or analytics is initialized. Native dependencies use Expo-compatible versions and the npm lockfile is committed.

## V2 kayıt modeli

Her parça seviye ve tür içerir. Aynı tür ve seviye birleşebilir; zincir türler arasında ilerleyebilir. V1 yüklenirken doğrulanarak V2’ye dönüştürülür, orijinal anahtar korunur. Kayıt öncesinde durum tekrar doğrulanır.
